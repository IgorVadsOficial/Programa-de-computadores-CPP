Fundamentos

O que é um Algoritmo?

Antes de aprender C++, precisamos entender o conceito de algoritmo. Um algoritmo é uma sequência lógica, finita e definida de instruções que devem ser seguidas para resolver um problema ou executar uma tarefa.

🥘 Analogia da Receita: Imagine uma receita de bolo. Ela tem uma lista de ingredientes (Entradas) e um passo a passo (Instruções) que resultam no bolo pronto (Saída). Isto é um algoritmo!

1. Entrada (Input)

Os dados necessários para o algoritmo trabalhar (ex: os números que quer somar).

2. Processamento

As regras e operações aplicadas aos dados de entrada para chegar a um resultado.

3. Saída (Output)

O resultado final entregue pelo algoritmo após a execução das tarefas.

Na computação, escrevemos algoritmos usando linguagens de programação para que o computador possa executá-los com altíssima velocidade.

Capítulo 1

Aplicações e Relevância

C++ não é apenas uma linguagem clássica; é o alicerce de sistemas que exigem o máximo de desempenho e controle de hardware.

🎮 Games

Motores gráficos como a Unreal Engine são escritos em C++. Jogos AAA como GTA V e Elden Ring dependem dele.

💻 Sistemas

Grandes partes do Windows, macOS e Linux são desenvolvidas em C++, além de navegadores como o Chrome.

🛰️ Aeroespacial

Sistemas de controle de foguetes da SpaceX e da NASA utilizam C++ pela sua previsibilidade e velocidade.

💡 Destaque: Onde a performance é crítica e a latência deve ser mínima, o C++ é a escolha principal.

Capítulo 2

O que é o C++?

Criado por Bjarne Stroustrup em 1979 (originalmente como "C com Classes"), o C++ é uma extensão da linguagem C que adicionou o paradigma de Programação Orientada a Objetos.

⚙️ Multiparadigma: Permite programar de forma procedural (como o C), orientada a objetos ou genérica.
🏗️ Baixo Nível com Abstração: Tem acesso direto à memória (ponteiros), mas também ferramentas modernas de alto nível.

Capítulo 3

Seu Primeiro Programa

Vamos analisar a estrutura básica de um código em C++ que exibe uma mensagem no terminal.

cpp — hello.cpp
#include <iostream> // Biblioteca de entrada e saída int main() { // std::cout é usado para imprimir no ecrã std::cout << "Olá, Mundo IFRN!" << std::endl; return 0; // Indica que o programa terminou com sucesso }
🔍 Nota: O <iostream> é necessário para usar o cout. Toda execução começa na função main.

Capítulo 4

Como Compilar

C++ é uma linguagem compilada. Isto significa que o código humano precisa de ser traduzido para linguagem de máquina antes de rodar.

Utilizando o Terminal (GCC/G++):

bash
# Compilar o ficheiro g++ hello.cpp -o meu_programa # Executar o programa ./meu_programa

Também pode usar IDEs como: Visual Studio Code, Code::Blocks, CLion ou Dev-C++.

Capítulo 5

Variáveis e Tipos de Dados

C++ é fortemente tipado. Cada variável deve ter um tipo definido para que o compilador reserve o espaço correto na memória.

cpp
int idade = 20; // Números inteiros double nota = 9.5; // Números decimais (alta precisão) float peso = 70.2f; // Números decimais (precisão simples) char inicial = 'J'; // Único caractere bool aprovado = true; // Verdadeiro ou Falso std::string nome = "ADS"; // Cadeia de caracteres (texto)
📏 Tamanhos: Um int geralmente ocupa $4$ bytes, enquanto um char ocupa apenas $1$ byte.

Capítulo 6

O Ciclo da Compilação

O que acontece entre o "guardar" e o "executar"? O processo é dividido em quatro etapas principais:

1. Pré-processador
Resolve #includes e macros
→
2. Compilador
Gera código Assembly
→
3. Montador
Gera código objeto (binário)
→
4. Linker
Une bibliotecas e gera o EXE
🛠️ Linguagem de Máquina: No final do processo, temos apenas zeros e uns ($0101$) que o processador consegue interpretar diretamente.

Abaixo estão as resoluções comentadas para os exercícios 3, 5 e 7.

Exercício 3: Média de 4 notas

cpp
#include <iostream> int main() { float n1, n2, n3, n4, media; std::cout << "Digite as 4 notas separadas por espaco: "; std::cin >> n1 >> n2 >> n3 >> n4; media = (n1 + n2 + n3 + n4) / 4; std::cout << "A media aritmetica e: " << media << std::endl; return 0; }

Exercício 5: Celsius para Fahrenheit

cpp
#include <iostream> int main() { float celsius, fahrenheit; std::cout << "Digite a temperatura em Celsius: "; std::cin >> celsius; fahrenheit = (celsius * 1.8) + 32; std::cout << "Temperatura em Fahrenheit: " << fahrenheit << std::endl; return 0; }

Exercício 7: Desconto de 10%

cpp
#include <iostream> int main() { float precoOriginal, precoComDesconto; std::cout << "Digite o preco do produto: "; std::cin >> precoOriginal; precoComDesconto = precoOriginal * 0.90; // 0.90 equivale a retirar 10% std::cout << "O valor com 10% de desconto e: R$ " << precoComDesconto << std::endl; return 0; }
